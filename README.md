# ClassFocus (수업집중)

수업 시작 → 학생 폰은 허용된 앱 외 사용 불가, 수업 종료 → 자유.

```
server/   Node.js (express + ws)  + 교사용 웹 콘솔(server/public/index.html)
android/  학생 앱 (Kotlin, Android Studio에서 android/ 폴더 열기)
ios/      학생 앱 (SwiftUI, 새 Xcode 프로젝트에 ClassFocusApp.swift 추가)
```

## 서버 실행
```
cd server && npm install && npm start     # http://localhost:3000
```
배포 시 HTTPS 필수 (Render / Fly.io / Railway 등). 앱의 서버 주소는 wss://도메인/ws

## 사용 순서
1. 교사: 서버 주소를 열어 "새 수업 만들기" → 6자리 코드를 학생에게 공유
2. 학생: 앱에서 서버 주소/코드/이름 입력, 권한 3개 켜고 "수업에 연결"
3. 교사: 학생 앱 목록에서 허용할 앱 체크 → "수업 시작" / "수업 종료"

## 안드로이드 동작 원리
- 접근성 서비스: 수업 중 허용 외 앱이 앞으로 나오면 즉시 수업집중 화면으로 복귀
- 기기관리자: 활성화되면 해제 전까지 앱 삭제 불가. 수업 중에는 '설정' 앱도 차단되어 해제 불가
- 수업 중 설정 해제/연결 끊김 → 교사 화면에 ⚠️ 표시

## 알려진 한계 (개인 폰)
- 수업 시간이 아닐 때 학생이 접근성/기기관리자를 끄고 삭제하는 것은 막을 수 없음 (교사 화면에서 감지만 가능)
- 완전한 강제는 학교 지급 기기 + MDM/Device Owner 필요
- iOS: 앱 삭제 방지는 수업 중에만 가능, 교사가 앱을 원격 지정 불가(학생이 미리 고른 앱 묶음만 허용),
  백그라운드 수신은 APNs 푸시 연동 필요(현재는 앱이 켜져 있을 때만 작동)
- 코드는 컴파일/실기기 테스트 전 초안입니다 (서버는 문법 검사만 완료)
